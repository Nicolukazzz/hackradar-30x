# Investigación

Un archivo por tema: `docs/research/<tema-en-kebab>.md`. Crear con `/investigar <tema>`.

Cada archivo: pregunta, hallazgos (con fuentes), implicación para el proyecto, preguntas abiertas.

Temas sugeridos para Blinka:
- Cómo hacen hoy AP (accounts payable) Ramp, Brex, Bill.com y qué reglas de aprobación ofrecen.
- Extracción de facturas con LLM (PDF, imagen, correo): precisión, confianza, costo.
- Detección de duplicados en facturas (número, monto, proveedor, fecha, fuzzy).
- Prompt injection en documentos (factura con instrucciones maliciosas).
- Diseño de registro auditable / explicaciones legibles.
- Formato de factura en Colombia, México, Brasil (DIAN, CFDI, NF-e) para facturas simuladas realistas.
